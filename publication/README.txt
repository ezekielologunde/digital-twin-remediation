EMPIRICAL MANUSCRIPT DRAFT v0.2, 5 October 2026

Status: drafted locally, not submitted or published.

The article covers 50 action trials in five successive development stages.
These are not 50 identically distributed trials, and shared policy views are
not independent observations. Prior development and excluded attempts are
documented. This is a case-study draft, not a new-defense or safety claim.

Overleaf use:
1. Upload Overleaf-case-study-v0.2.zip as a new project.
2. Select main.tex as the main document and use pdfLaTeX.
3. Compile twice for citation/table references and inspect the resulting PDF.
4. Resolve author/declaration placeholders and review every claim before release.

The source is standalone, with inline bibliography and generated tables. No
external figures or custom classes are required. A clean PDF build has NOT
been verified: the built-in compiler returned an environment initialization
error, "Unable to find standard directories for platform". No PDF is included.
Do not confuse source checks with successful compilation or visual validation.

Research-evidence-v0.2.zip contains the raw selected batches, excluded attempts,
analysis programs, source snapshots and generation scripts. The MANIFEST.json
records payload hashes. REPLAY.txt gives commands that do not start Docker.
Live reruns require pinned images/runtime assets and adaptation of original
host bind paths. No Docker images or database volumes are redistributed.
