The earlier completed batches use Compose start, whose command receipts were retrospectively audited. Thirty receipts reported only the target starting; none reported an additional container start. This is an audit of recorded starts, not proof of absence of every indirect side effect. The scope deviation became material when MongoDB, a declared Compose dependency, was deliberately stopped in the direct-probe stage.

Each retained batch saves raw request and command ledgers, before-action predictions where applicable, source/configuration copies, outcome observations and scoped cleanup records. Data generated by earlier development cannot be relabeled as held-out validation for a later method designed after seeing it.

Overleaf-research-protocol-v0.2.zip remains the historical pre-pilot protocol. Overleaf-case-study-v0.2.zip is the later empirical author-review draft covering five selected stages and 50 action trials. It discloses development adaptation, excluded attempts, probe interventions and unverified source-to-binary provenance. It is not submitted; authorship/declarations and a verified PDF build remain pending.

## Cached-evidence replay

[Exhaustive subset replay](refresh-replay/Results.md) evaluates all eight fixed subsets of refreshed obligations on the corrected direct-probe batch. No new live outcomes are added. Cached evidence alone gives 12 false approvals among 18; every proper fixed subset misses an injected failure class; full refresh gives 0 among 6. Policies were constructed after outcomes, and recorded component sums are not actual selective execution times. This analysis does not isolate elapsed age from the intervening state change.
